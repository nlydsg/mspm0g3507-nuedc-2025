# 2025 电赛第一题 · MSPM0G3507 循迹小车

2025 年全国大学生电子设计竞赛第一题的实现，主控为 TI **MSPM0G3507**，开发环境 CCS + SysConfig。

## 功能

- **7 路灰度循迹**（L3 L2 L1 M R1 R2 R3），按题目要求分档执行不同赛道流程
- **编码器测速**：左右增量式编码器，5 ms 定时中断读取并清零计数
- **电机控制**：TB6612 双路驱动，PWM 差速转向
- **姿态采集**：WIT 串口姿态模块，提供 Yaw 角度用于直线保持与转向判断
- **OLED 多界面**：按键切换 3 个界面，实时显示灰度值、左右编码器计数与各状态标志
- **按键交互**：KEY1 切界面，KEY2 启停循迹，KEY3 切换题目档位（0–5）
- **状态提示**：LED 与蜂鸣器

## 硬件

| 模块 | 说明 |
| --- | --- |
| 主控 | TI MSPM0G3507（Arm Cortex-M0+，80 MHz） |
| 循迹 | 7 路灰度传感器 |
| 姿态 | WIT 串口姿态传感器（Yaw） |
| 电机 | TB6612 双路电机驱动 + 双直流减速电机 |
| 测速 | 左右增量式编码器 |
| 显示 | OLED（当前使用硬件 I2C 版本） |
| 交互 | 3 个按键、LED、蜂鸣器 |

## 软件结构

```
main.c                 主循环、OLED 界面、按键处理、5 ms 中断
main.h                 全局变量与头文件汇总
zcbsbz.syscfg          SysConfig 外设配置（GPIO / PWM / 定时器 / 串口 / I2C）
Drivers/
  MSPM0/               时钟与中断配置
  XUNJI/               灰度循迹采样与执行逻辑
  Encoder/             编码器计数
  TB6612/              电机驱动
  WIT/                 串口姿态模块解析
  OLED_Hardware_I2C/   OLED 驱动（当前使用）
  LED_BUZZ/            LED 与蜂鸣器
  MPU6050/ BNO08X_UART_RVC/ Ultrasonic_*/  备选传感器驱动（主流程暂未启用）
  OLED_Hardware_SPI/ OLED_Software_*       其他 OLED 驱动版本
targetConfigs/         调试器与目标板配置
```

## 控制流程

```
5 ms 定时中断
  ├─ 读取左右编码器计数并清零
  ├─ 采集 7 路灰度
  └─ 按当前题目档位执行循迹动作（差速转向 / 停车）

主循环
  ├─ 按键扫描（界面 / 启停 / 档位）
  └─ OLED 刷新
```

## 编译与运行

1. 使用 **CCS（Code Composer Studio）** 导入本目录工程
2. 打开 `zcbsbz.syscfg` 确认外设配置（SysConfig 会自动生成初始化代码）
3. 选择 MSPM0G3507 目标，编译并下载
4. KEY2 启动循迹，KEY3 切换题目档位，KEY1 切换显示界面

编译输出目录（`Debug/`）、CCS 本地设置（`.settings/`）与 clangd 缓存已通过 `.gitignore` 排除。
